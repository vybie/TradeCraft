**TradeCraft 0.2.0 alpha**

The new preview brings the egui-charts terminal to TradeCraft: chart layouts, drawing tools, indicators and settings, symbol search, and a watchlist with provider quotes.

Tradier now shares one live market-data connection across charts and the watchlist, with automatic reconnects and recovery of available chart history. Yahoo remains available as a delayed source. The Windows app also has the new crosshair icon and no separate console window.

This is an early read-only alpha. Data availability depends on the provider and market session, Pine Script isn't supported, and some terminal features and compliance items remain open. See the README and architecture audit for details.
