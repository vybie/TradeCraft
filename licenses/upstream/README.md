# Additional upstream license texts

Some Cargo packages omit license files from the published crate. These upstream texts supplement the dependency inventory generated by `scripts/package-community.py`:

- `clipboard-win` 5.4.3: Boost Software License 1.0 from upstream revision `ed27008ae5d1f10cfbb266de039f0fb35fd05a56`; the supplied copy matches the Git blob at that revision.

- `accesskit`: AccessKit repository at `f3026222559c7f5f46d8f25cb7404de68eb149f0`.
- `profiling`: profiling repository at `8271551172eb6fa4cba47369aedd93790c623df9`.
- `spirv`: rspirv repository at `8afc3d0ac8e158128cd1410bb2e4b4c26ab11bb4`.
- `egui`: egui repository's main branch, retrieved November 12, 2026. The exact packaged egui revision was not available from the advertised repository and still needs provenance review.
- `enum-map`: MIT license text from the enum-map 3.1.0 source revision `a09d924a4afde4e2864a1df7b1438a5e6cdf3e7e`. The crate's SPDX copyright statements are collected from the published crate's source files in the generated notice bundle. The enum-map-derive 1.0.1 package declares the same license choice and contains per-file SPDX copyright notices; its advertised commit `ccf562d340723530d54f7b1782b4ded803a7` could not be retrieved at the same license path. Its exact upstream license-file provenance remains open.
- `objc2`: MIT text from `e282618be4c3a3b9542957e0c8540e9588472ce8`; the same text was confirmed at `4fc083f1c6d6784577e38b0ee8dbd344481e2fd2` and `5237cbf081d04ef75a1f6a207b4018e7c1ae7438`. The previously unavailable exact revisions for the newer packages can now be inspected: [`block2` 0.6.2](https://github.com/madsmtm/objc2/blob/b4167b582b2f75f9a1be75495c41b765344fd03c/LICENSE.md), [`objc2` 0.6.5](https://github.com/madsmtm/objc2/blob/d7d2fa23ceaa5e6096c923b081040e5d81b3b9df/LICENSE.md), [`objc2-encode` 4.1.0](https://github.com/madsmtm/objc2/blob/8d214f5477365ffcbcbb7de058c86ed9a518efb7/LICENSE.md), and the [six 0.3.2 framework packages](https://github.com/madsmtm/objc2/blob/7b1abfd750a2cacaea71d6a56ecfb83cb7de560b/LICENSE.md). The revision identifiers come from the published crates' `.cargo_vcs_info.json` files. Each revision's policy identifies the applicable MIT option, but does not itself contain a full MIT notice with copyright holders. The older Steven Sheldon notice has not been established as complete for these newer revisions, so they remain outside the supplement mapping pending a defensible notice review. Upstream also expressly raises uncertainty about distribution of Apple SDK-derived crates; that question remains open separately from the Cargo license expressions.
- `dispatch` 0.2.0 declares MIT and names Steven Sheldon as author in its [exact source manifest](https://github.com/SSheldon/rust-dispatch/blob/82d6c7a5b75dc0c71c3f46f87bb6c16a476f7748/Cargo.toml). Neither its published crate nor the root of that revision contains a license file; the precise copyright notice remains unresolved. On the macOS graph it enters through `objc2-foundation` 0.2.2 and both accessibility and `winit`, so disabling accessibility alone does not remove it.

The generated inventory identifies packages for which no license file was present locally. These supplementary files do not replace the open dependency and distribution review in `ARCHITECTURE.md`.
