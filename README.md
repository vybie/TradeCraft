# TradeCraft alpha

TradeCraft remains in alpha until announced otherwise. Versions use `0.minor.patch`: the minor number advances for feature milestones and the patch number for fixes and small improvements. This release is `0.3.0`. The workspace version in `Cargo.toml` is the source of truth; release tags and packages use the same version, such as `v0.3.0`. A version number is not reused for a different release.

A native Rust charting experiment using the egui/eframe stack and the development version of egui-charts. It loads one-, five-, fifteen-minute or daily chart history from Yahoo, Tradier, or Kraken for supported crypto pairs; Tradier streams market price updates for charts and the watchlist over one shared connection. It does not request account information, positions, or order history. Chart and price timestamps use the computer's local time in 12-hour format.

For Tradier symbols, the interval menu also offers individual trade ticks and weekly and monthly candles. Tick history is limited to recent sessions; extended-hours availability varies by symbol. Tick recovery after a stream interruption covers up to ten minutes; timestamps shared by multiple trades and provider delays can leave the history/live boundary imperfect. Other tick groupings, volume, range, delta and millisecond bars are not yet implemented.

Extended hours are enabled by default. Changing the symbol, interval or extended-hours setting reloads chart history; the shared Tradier stream updates its symbol list without a separate connection. Regular-hours mode uses Tradier's market calendar to filter live prices, including early closes. Tradier's available extended-hours history is limited.

The main window uses the egui-charts terminal, including its indicator catalog, study settings, drawing tools, chart types and layouts. Terminal settings, drawings, templates and named layouts are stored under the local TradeCraft application-data folder. Some upstream terminal features are incomplete or require services TradeCraft does not provide; see the architecture report.

Use the **+** above the toolbar to open another chart tab and choose its symbol. The app saves open tabs and their chart snapshots with user settings and restores them on restart or after changing market-data settings. Experimental Pine studies retain the source used when applied, independently of later edits. Other unregistered custom studies cannot yet be restored; the last complete workspace snapshot is kept and a warning is shown. Named layouts remain separate.

On quit, TradeCraft waits for pending saves. If saving fails or takes longer than expected, it remains open and offers retry, a return to the app, or a separately confirmed quit without saving. On Windows, closing the window still minimizes it to the notification area; use the tray menu to quit.

The watchlist shows provider quotes and changes, and symbol search supports company names and tickers. Tradier watchlist prices update from the shared stream; an initial batched quote request supplies the previous close. Yahoo quotes are based on completed candles delayed by at least 15 minutes and refresh approximately once a minute. Kraken's supported crypto spot pairs are available in symbol search and use its public live ticker and candle streams. Crypto watchlist changes are rolling 24-hour changes. BTCUSD remains an alias for Kraken's BTC/USD. Kraken's spot history returns at most 720 recent candles, including the current candle. Provider availability and entitlements apply.

## Run

Install Rust, then run `cargo run --release`. The default Yahoo Finance chart uses an unofficial endpoint and is delayed by at least 15 minutes. Open the TradeCraft icon menu and choose Market data settings to select Tradier and enter your own production token. TradeCraft stores its own Tradier token in Windows Credential Locker or macOS Keychain, never in settings.json. The Yahoo endpoint is unofficial; check Yahoo's terms and data rights before distributing an app that uses it.

Community builds use `cargo build --release` and exclude the VibesTrader credential shortcut. Community provider preferences are stored separately in `settings-community.json`, so they start with Yahoo even if the personal build already uses Tradier. The personal build keeps its existing `settings.json`. Both files are under the local TradeCraft application-data folder. If both builds use a manually entered Tradier token, they share its Windows Credential Locker entry. For a personal build that includes the shortcut and updates the taskbar-pinned executable, run `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-personal.ps1`. The script builds in a separate directory, verifies the result and replaces `target/personal/tradecraft.exe`, which the pin launches. A running TradeCraft window keeps the old build until fully quit and reopened; the previous executable is retained as a backup.

On Windows, closing the window minimizes TradeCraft to the taskbar. Click its notification-area icon to reopen it, or use the icon's menu to quit. Quitting releases its market-data connection.

### macOS build

On a Mac with Rust and Xcode command line tools installed, run `bash scripts/build-macos.sh`. The community app and zip are created under `target/packages`; pass `aarch64-apple-darwin` or `x86_64-apple-darwin` to select an installed Rust target. The macOS GitHub Actions workflow also builds both architectures. These builds are unsigned and not notarized. macOS stores app data in `~/Library/Application Support/TradeCraft` and manually entered Tradier credentials in Keychain. The Windows-only VibesTrader credential shortcut is excluded. Closing the macOS window quits the app; menu-bar behavior is not implemented.

The workspace layout, Craft standards audit, verification commands, and remaining gaps are documented in [ARCHITECTURE.md](ARCHITECTURE.md). Informal community releases include and link that compliance log so the community can review open findings.

Planned features and progress are tracked in [ROADMAP.md](ROADMAP.md).

Release changes are recorded in [CHANGELOG.md](CHANGELOG.md). The TradeCraft menu includes an experimental Pine indicator editor. Open Indicators → Custom Pine → Manage Pine scripts to save, edit, or delete library entries; clicking an entry adds it to the chart. It implements a subset of Pine, including some v4 scripts; strategies are not supported. Studies stop on reported runtime errors or charts over 10,000 bars. Realtime bar-state semantics, lower-timeframe requests, tables and drawings are incomplete. Same-symbol daily security requests use the provider daily history; other higher-timeframe values are built from loaded chart bars. The newest bar is approximate. Pine session times and calendar aggregation use the chart timezone setting. The sample scripts/pine/bb-levels.pine calculates US regular hours in New York time regardless of the chart display timezone, and uses provider daily history for prior-day levels. Results depend on available history and extended-hours data. Do not rely on Pine output for trading decisions. Tradier's Brokerage API does not provide futures; the app does not supply an overnight futures-derived SPX chart.

List the supported state commands with `cargo run -- --commands`. An isolated, offline command script can be run with `cargo run -- --script path/to/script.json`; it accepts a JSON array and prints the resulting workspace. It does not connect to market data, save settings, or control a running window.

This alpha uses real market data, but it is not ready to make trading decisions. After a Tradier stream interruption, TradeCraft requests missed chart history, then reconciles the forming candle at a completed one-minute boundary while buffering newer ticks. Recovery is limited by the provider's available history and is retried if data is unavailable. Initial history/stream overlap, exchange corrections and late trades still need further verification. The chart can show the last downloaded history while disconnected. Tradier may not send trades outside market hours. The app is read-only and does not place orders.

Tradier permits one market-data stream at a time. TradeCraft shares its stream across chart and watchlist symbols and updates its subscriptions as symbols change. Avoid opening a second market stream with the same account in another app. REST calls, including initial quote snapshots and symbol search, count against Tradier's per-token market-data rate limit. Alert definitions and statuses are saved locally; alerts are evaluated only while the app is open.
